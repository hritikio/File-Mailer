# 📧 MailProject – Email Sending Application

A full-stack email sending application with a separate **Frontend** and **Backend**, built to send emails securely using environment variables.

---

## 🚀 Features
- Send emails using a backend service
- Secure handling of credentials using `.env`
- Clean separation of frontend and backend
- Easy local setup

---

## 🛠️ Tech Stack

### Frontend
- Vite + React
- HTML, CSS, JavaScript
- axios
- react-router-dom
- tailwind

### Backend
- Node.js
- Express.js
- MongoDB
- Nodemailer
- multer
- zod
- dotenv
---

# ▶️ Project Setup & Run Guide

This document explains how to set up environment variables and run the project locally.



## 📋 Prerequisites

Make sure you have the following installed:

- Node.js (v18 or later recommended)
- npm
- MongoDB (local or cloud)
- Git

---

## 📂 Backend Setup


```bash
-Navigate to Backend folder
  cd Backend

-Rename .env.example to .env

-Add environment variable values

-Running the Backend
  npm install
  npm start
```

## 📂 Frontend Setup


```bash
-Navigate to the Frontend folder
  cd Frontend
-Install required packages
  npm install
-Start the Frontend Development Server
  npm run dev
The frontend will start at:
  http://localhost:5173
